# Michi Website

Static website for michidecisions.com.

## Deploy to GitHub Pages

1. Create a GitHub repository, for example `michi-website`.
2. Upload all files in this folder to the repository root.
3. In GitHub, go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/root`, then save.
6. Point `michidecisions.com` to the GitHub Pages site in your DNS settings.

## Files

- `index.html` — site content
- `styles.css` — site styling
- `assets/images/` — logos, screenshots, hero images


## Required legal URLs
This site includes GitHub Pages-friendly folders for the URLs used in the app:

- /terms-of-use/
- /privacy-policy/
- /support/

With the custom domain `www.michidecisions.com`, these resolve as:

- https://www.michidecisions.com/terms-of-use
- https://www.michidecisions.com/privacy-policy
- https://www.michidecisions.com/support
